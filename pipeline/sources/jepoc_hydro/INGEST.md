# JEPOC 水力発電所データベース

## 概要

電力土木技術協会（JEPOC）建的水力发电所数据库。**会员非会员都可用，无需凭据。**

| 项 | 值 |
|---|---|
| 收录范围 | **電気事業用：全部**；自家用：最大出力 **≥1,000kW** |
| 规模 | 全国 **240 个水系**（北海道 24 / 東北 52 / 関東 16 / 中部 19 / 北陸 16 / 近畿 20 / 中国 30 / 四国 18 / 九州 44 / 沖縄 1） |
| 坐标 | ❌ **没有** —— 见下 |
| 数据时点 | **2014.11.30 入力，之后未更新** |
| 技术栈 | 老式 PHP（prototype.js、FCKeditor），2014 年建 |

## ⚠️ 没有坐标 —— 立项调研写错了

立项调研笔记写着「含坐标」。**实测是错的**：详细页的所在地字段只到
**都道府県 + 市町村**，没有经纬度。

**所以本源补不了 AJG 的水力坐标缺口。** 拿它当坐标源的计划要作废。

## 那它的价值在哪

**水力建模参数 —— AJG 和 GEM 都没有的东西。**

最关键的是 **`発電方式`**，它是「水力是三类资产不是一类」的判别依据：

| 発電方式 | 建模含义 |
|---|---|
| **流込み式** | 固定出力时序，像光伏一样不可调度 |
| **調整池式 / 貯水池式** | **带入流的储能** —— 能量约束与燃料制約同构 |
| **混合揚水式 / 揚水式** | 标准储能对（往返效率约 70%） |

北海道实测分布：流込み式 38 / 調整池式 35 / 貯水池式 24 / 混合揚水式 2。
**把水力当一类资产建模是错的**，这个字段是纠正它的依据。

其他参数：最大出力 / 常時出力 / 最大使用水量 / 有効落差 / 取水位 / 放水位 /
流域面積 / 水系名 / 河川名 / 級別。

另外「市町村 + 発電所名」可用于**同名消歧**（例：多个「〇〇第一発電所」）。

## 获取

**类型：`auto`** —— 无凭据。

```bash
python -m pipeline.sources.jepoc_hydro.ingest            # 只抓一览（约 250 请求，8 分钟）
python -m pipeline.sources.jepoc_hydro.ingest --detail   # 连详细页（慢很多）
python -m pipeline.sources.jepoc_hydro.ingest --area 1
```

### 导航结构

```
GET  /hydro/                                                    建 session
POST /hydro/index.php?_w=usData&_x=areashow2   AreaNo=01..10    → 水系列表
POST /hydro/index.php?_w=usData&_x=areashow3   AreaNo + RiverSystemNo → 発電所一覧
GET  /hydro/index.php?_w=usData&_x=detail2&pp=1&OwnerNo=&AreaNo=&RiverSys=&fd=  → 详细
```

### 一览页 vs 详细页

| 字段 | 一览 | 详细 |
|---|:-:|:-:|
| 発電所名 / 事業者名 / 水系名 | ✅ | ✅ |
| 出力(kW) / 発電形式 / 発電方式 | ✅ | ✅ |
| 運転開始年月 | ✅ | ✅ |
| 有効落差 / 最大使用水量 / 取水位 / 放水位 | — | ✅ |
| 流域面積 / 河川名 / 級別 | — | ✅ |
| **所在地（都道府県 + 市町村）** | — | ✅ |

一览页已覆盖大部分需求，**详细页是可选项**（`--detail`）。

## 已知坑

- **没有坐标**（见上）。别再把它当坐标源。
- **数据停在 2014 年**。2014 年之后新建的中小水力**不会在里面**，
  用它做「全量清单」会漏。跟 FIT 数据（C1）交叉才能覆盖新建的。
- **`AreaNo` 必须与 `RiverSystemNo` 一起传**。只传后者会返回空表（表头在但无数据行），
  而且**不报错** —— 又一个「空 200 伪装成成功」的例子。
- **地方划分是「地理地方」不是「电力区域」**：这里的「関東」「中部」「北陸」「近畿」
  与 10 电力区域**不一致**（如 JEPOC 的中部 ≠ 中部電力管内）。跨源 join 时不能直接用。
- 発電方式的写法不统一：`流込み式` / `流込式` 混用，多系统时用 `／` 连接
  （`調整池式／調整池式`）。归一化时要处理。
