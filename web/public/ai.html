powerjp — Japan power-grid data and observed flow map

powerjp is a reproducible pipeline and static web map for exploring Japan's power-system topology, substations, generation facilities, and observed transmission-line power flow.

What it provides

  • Transmission-line and substation geometry where a source-backed geometry is available.
  • Generation-site and unit-output layers with source and quality metadata.
  • Observed trunk-line power flow at 30-minute resolution.
  • A time-aware GeoJSON map distributed through a CDN.

Geographic and temporal scope

The project covers Japan's power system. Flow and unit-output records use 30-minute observations where the source provides them. Area supply-demand data is hourly upstream data used for derived estimates; it is not republished as source CSV files.

Sources

Published artifacts combine or derive from All-Japan-Grid, OpenStreetMap, OCCTO public power-system data, Japan's MLIT National Land Numerical Information, and Global Energy Monitor. The application displays attribution and links to the relevant source terms.

Important limitations

  • powerjp is an observation and data-visualization project, not an operational control or dispatch system.
  • Observed flow is not a newly calculated AC power-flow solution.
  • Some flow records do not have a source-backed physical geometry and are therefore not drawn as a line.
  • Data artifacts may have source-specific redistribution conditions. Do not treat the code licence as a licence for every data artifact.
